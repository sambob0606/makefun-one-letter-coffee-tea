One letter for the coffee-vs-tea argument, picked by a program for make.fun's "One Letter: Coffee or Tea" bounty. The program scores both candidates on the judge's own criteria — vivid first, then funny, then true, then how well the letter stands alone — and writes the winning letter to `/output/entry.txt`. The winner is **A**, for coffee: bold, dark, steaming, a jolt you can feel before the first sip finishes, and the morning's blunt, honest ritual.

## Run it

```sh
python3 main.py
```

It writes exactly one character (`A`, no trailing newline) to `/output/entry.txt`, then reads it back and verifies the gate (exactly one byte, one of the two letters) before exiting.
